# VPN App — тестовые лендинги

В корне находится страница выбора. Четыре варианта доступны по адресам `/market_lend_1/` … `/market_lend_4/`.

## Сборка и публикация в Cloudflare Workers

```sh
npm ci
npm run deploy
```

`wrangler.toml` публикует каталог `dist/`. Сборка копирует только страницу выбора и четыре лендинга. ZIP-архивы Keitaro в публикацию не попадают. Для локального просмотра можно открыть `index.html` через любой статический сервер.

Ссылки `{offer}` внутри лендингов предназначены для подстановки в Keitaro. На тестовом сайте Cloudflare они остаются заглушками.
